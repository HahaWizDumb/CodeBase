A sorcerer's scroll · Novice to Adept

The Scroll of JEV

How to raise your own research familiar: an AI that reads your sources, checks claims against evidence, admits what it doesn't know, and convenes a council of minds to brainstorm with you. All you need is a computer, patience, and the willingness to copy spells carefully.

The first truth of the craft: you do not forge the mind from nothing. Training a large language model from scratch costs millions. Instead, a sorcerer binds an existing open model and surrounds it with organs of their own design. JEV is those five organs working together.

The MindA language model running on your machine (Ollama)
The CharterStanding rules: cite, doubt, admit ignorance
The LibraryYour documents, searchable by meaning
The Truth-SeerA pipeline that judges claims against evidence
The CouncilSeveral personas that argue, then synthesize
I
First Circle · Apprentice

Gather the Reagents

Every working needs its materials. You will install three things, each free: a Python interpreter to speak spells, an editor to write them, and Ollama, which houses the model on your own machine so your research never leaves it.

  1. Python 3.11 or newer from python.org. On Windows, tick "Add python.exe to PATH" during install.
  2. VS Code from code.visualstudio.com, then add its Python extension.
  3. Ollama from ollama.com. It runs quietly in the background and serves models at http://localhost:11434.

Now summon a mind. Open a terminal (Terminal on macOS, PowerShell on Windows) and speak:

Terminal

ollama pull nomic-embed-text
ollama run llama3.1:8b "Name three uses of a fact-checking assistant."

The first model is the Mind. The second, nomic-embed-text, is a small model that turns text into coordinates of meaning; the Library will need it in the Fourth Circle.

II
Second Circle · Apprentice

The First Incantation

A conversation with a model is a list of messages. Each has a role (who speaks) and content (what is said). The system role carries standing orders, user is you, and assistant is JEV. The model has no memory between calls; you give it memory by sending the whole list each time.

jev_chat.py
import ollama

MODEL = "llama3.1:8b"
history = [{"role": "system", "content": "You are JEV, a careful research assistant."}]

while True:
    question = input("\nYou: ")
    if question.lower() in ("quit", "exit"):
        break
    history.append({"role": "user", "content": question})
    reply = ollama.chat(model=MODEL, messages=history)
    answer = reply["message"]["content"]
    history.append({"role": "assistant", "content": answer})
    print("\nJEV:", answer)

Run it with python jev_chat.py. You now have a familiar that speaks. It is also, at this stage, a confident liar: it will answer from memory, invent citations, and never say "I'm not sure." The next circles fix that.

IV
Fourth Circle · Initiate

The Library

A model's memory is blurry and frozen at its training date. The Library gives JEV sharp, current, verifiable knowledge: your own PDFs and notes. The technique is called retrieval-augmented generation, or RAG, and it works in three motions.

  1. Cut each document into passages of a few hundred words, overlapping slightly so no idea is sliced in half.
  2. Embed each passage: the embedding model turns it into a list of numbers that places it on a map of meaning. Passages about similar ideas land near each other.
  3. Summon: when you ask a question, embed the question too, fetch the nearest passages, and hand them to the Mind as evidence.

Place your PDFs and .txt files in a folder named tomes, then cast the binding:

library.py
import pathlib, ollama, chromadb
from pypdf import PdfReader

EMBED = "nomic-embed-text"
db = chromadb.PersistentClient(path="jev_library")
shelf = db.get_or_create_collection("tomes")

def read_tome(path):
    if path.suffix.lower() == ".pdf":
        pages = PdfReader(path).pages
        return [(i + 1, p.extract_text() or "") for i, p in enumerate(pages)]
    return [(1, path.read_text(encoding="utf-8", errors="ignore"))]

def cut(text, size=180, overlap=40):
    words = text.split()
    step = size - overlap
    for start in range(0, max(len(words), 1), step):
        piece = " ".join(words[start:start + size])
        if piece.strip():
            yield piece

def embed(text):
    return ollama.embed(model=EMBED, input=text)["embeddings"][0]

def bind_library(folder="tomes"):
    for path in pathlib.Path(folder).glob("*"):
        if path.suffix.lower() not in (".pdf", ".txt", ".md"):
            continue
        for page, text in read_tome(path):
            for n, piece in enumerate(cut(text)):
                shelf.upsert(
                    ids=[f"{path.name}-p{page}-{n}"],
                    documents=[piece],
                    embeddings=[embed(piece)],
                    metadatas=[{"source": path.name, "page": page}],
                )
        print("Bound:", path.name)

def summon(question, k=5):
    hits = shelf.query(query_embeddings=[embed(question)], n_results=k)
    return [
        {"text": d, "source": m["source"], "page": m["page"]}
        for d, m in zip(hits["documents"][0], hits["metadatas"][0])
    ]

if __name__ == "__main__":
    bind_library()

Run python library.py once to bind your tomes; run it again whenever you add new ones. The library persists in the jev_library folder.

V
Fifth Circle · Journeyman

The Truth-Seer

Fact-checking is not one question but three steps, and a small model does each far better alone than all at once. Split the text into single claims, gather evidence for each, then judge each claim only against that evidence.

truthseer.py
import json, ollama
from library import summon

MODEL = "llama3.1:8b"
CHARTER = open("charter.txt", encoding="utf-8").read()

def ask(prompt, as_json=False):
    reply = ollama.chat(
        model=MODEL,
        messages=[{"role": "system", "content": CHARTER},
                  {"role": "user", "content": prompt}],
        format="json" if as_json else None,
        options={"temperature": 0},   # steady hand, no improvising
    )
    text = reply["message"]["content"]
    return json.loads(text) if as_json else text

# Step 1: split text into atomic, checkable claims
def extract_claims(text):
    out = ask(
        "List every checkable factual claim in the text below as short standalone "
        'sentences. Reply as JSON: {"claims": ["..."]}\n\n' + text,
        as_json=True)
    return out.get("claims", [])

# Steps 2 and 3: gather evidence, then judge only against it
def judge(claim):
    evidence = summon(claim, k=5)
    numbered = "\n\n".join(
        f"[{i+1}] ({e['source']}, p.{e['page']}) {e['text']}"
        for i, e in enumerate(evidence))
    verdict = ask(
        f"CLAIM: {claim}\n\nEVIDENCE:\n{numbered}\n\n"
        "Judge the claim using ONLY the evidence above. Reply as JSON: "
        '{"verdict": "SUPPORTED" | "REFUTED" | "NOT ENOUGH EVIDENCE", '
        '"cited": [evidence numbers], "reason": "one sentence"}',
        as_json=True)
    verdict["claim"] = claim
    verdict["sources"] = [evidence[n-1] for n in verdict.get("cited", [])
                          if isinstance(n, int) and 0 < n <= len(evidence)]
    return verdict

def fact_check(text):
    return [judge(c) for c in extract_claims(text)]

if __name__ == "__main__":
    for v in fact_check(input("Paste text to check: ")):
        print(f"\n{v['verdict']}: {v['claim']}\n  why: {v.get('reason')}")
        for s in v["sources"]:
            print(f"  - {s['source']} p.{s['page']}")
Ward. "Not enough evidence" is a victory, not a failure. A Truth-Seer that always reaches a verdict is guessing. Test it with a claim your tomes don't cover and make sure it refuses to rule.
VI
Sixth Circle · Journeyman

Scrying the World

Your Library only knows what you've fed it. To check claims about the wider world, JEV needs a scrying glass: a web search it can consult. The pattern is identical to the Library, only the evidence comes from search results instead of your tomes.

Choosing a glass

GlassCostNotes
SearXNGFree, self-hostedRuns on your machine; private; takes some setup (Docker).
A search API (Brave, Tavily, others)Free tier, then paidEasiest. Sign up, get a key, send one web request.
Wikipedia APIFree, no keyNarrow but excellent for a first experiment.

Start with Wikipedia, which needs no account. Add requests with pip install requests:

scry.py
import requests

def scry(query, k=3):
    """Search Wikipedia and return short passages in the same shape as summon()."""
    api = "https://en.wikipedia.org/w/api.php"
    headers = {"User-Agent": "JEV-research-familiar/0.1"}
    found = requests.get(api, headers=headers, params={
        "action": "query", "list": "search", "srsearch": query,
        "srlimit": k, "format": "json"}).json()
    results = []
    for hit in found["query"]["search"]:
        page = requests.get(api, headers=headers, params={
            "action": "query", "prop": "extracts", "explaintext": 1,
            "exintro": 1, "titles": hit["title"], "format": "json"}).json()
        text = next(iter(page["query"]["pages"].values())).get("extract", "")
        results.append({"text": text[:1500], "source": "Wikipedia: " + hit["title"], "page": 1})
    return results

Because scry() returns the same shape as summon(), you can blend them in the Truth-Seer: evidence = summon(claim, 3) + scry(claim, 2). JEV now weighs your private tomes and the public record side by side.

Lore. Search engines match keywords, not meaning. Before scrying, ask the Mind to rewrite the claim as a short search query ("Rosetta Stone discovery year") for far better results.
VII
Seventh Circle · Adept

The Council

Here JEV becomes a think tank. One model can wear many masks. Give each mask a distinct duty, let them respond to the same question in turn, each reading what came before, and finally let a Moderator weave the debate into a single brief. Disagreement is the point; a council that always agrees is one voice in costume.

The VisionaryProposes bold ideas and unexplored directions.
The SkepticHunts for weak evidence, hidden assumptions, and failure modes.
The HistorianFinds precedent: who tried this before and what happened.
The PragmatistTurns ideas into first steps, costs, and a timeline.
council.py
import ollama

MODEL = "llama3.1:8b"
SEATS = {
    "Visionary":  "Propose three bold, specific ideas. Favor the unexplored.",
    "Skeptic":    "Attack the ideas so far. Name weak evidence and hidden assumptions.",
    "Historian":  "Cite real precedents for these ideas and what became of them. Say so if unsure.",
    "Pragmatist": "Pick the most promising idea and give five concrete first steps.",
}

def speak(duty, transcript):
    reply = ollama.chat(model=MODEL, options={"temperature": 0.8}, messages=[
        {"role": "system", "content": f"You sit on a research council. Your duty: {duty} Be concise."},
        {"role": "user", "content": transcript},
    ])
    return reply["message"]["content"]

def convene(question, rounds=2):
    transcript = f"QUESTION BEFORE THE COUNCIL: {question}\n"
    for r in range(rounds):
        for name, duty in SEATS.items():
            words = speak(duty, transcript)
            transcript += f"\n--- {name} (round {r+1}) ---\n{words}\n"
            print(f"\n[{name}]\n{words}")
    brief = speak("You are the Moderator. Summarize: best ideas, strongest objections, "
                  "open questions, and a recommended next step.", transcript)
    print("\n=== MODERATOR'S BRIEF ===\n" + brief)
    return brief

if __name__ == "__main__":
    convene(input("What shall the council consider? "))

Notice the temperature: 0 for the Truth-Seer, 0.8 for the Council. Low temperature makes answers steady and repeatable; high temperature makes them varied and inventive. Judgment wants the first, brainstorming the second.

VIII
Eighth Circle · Adept

The Face

A familiar confined to the terminal is hard to share. Streamlit gives JEV a face in your web browser with a few dozen lines: three chambers for asking, checking, and convening.

app.py
import streamlit as st, ollama
from library import summon
from truthseer import fact_check, CHARTER, MODEL
from council import convene

st.set_page_config(page_title="JEV", page_icon="✶")
st.title("✶ JEV")
ask_tab, check_tab, council_tab = st.tabs(["Ask", "Fact-check", "Council"])

with ask_tab:
    q = st.text_input("Ask the library")
    if q:
        ev = summon(q)
        context = "\n\n".join(f"({e['source']} p.{e['page']}) {e['text']}" for e in ev)
        reply = ollama.chat(model=MODEL, messages=[
            {"role": "system", "content": CHARTER},
            {"role": "user", "content": f"SOURCES:\n{context}\n\nQUESTION: {q}"}])
        st.write(reply["message"]["content"])
        with st.expander("Passages consulted"):
            for e in ev:
                st.caption(f"{e['source']} · p.{e['page']}")
                st.write(e["text"])

with check_tab:
    text = st.text_area("Paste a passage to check", height=180)
    if st.button("Check claims") and text:
        with st.spinner("The Truth-Seer deliberates..."):
            for v in fact_check(text):
                mark = {"SUPPORTED": "🟢", "REFUTED": "🔴"}.get(v.get("verdict"), "🟡")
                st.markdown(f"{mark} **{v.get('verdict')}**: {v['claim']}")
                st.caption(v.get("reason", ""))

with council_tab:
    topic = st.text_input("Question for the council")
    if st.button("Convene") and topic:
        with st.spinner("The council debates..."):
            st.markdown(convene(topic, rounds=1))

IX
Ninth Circle · Adept

Wards & Trials

An adept does not trust their familiar; they test it. Build a trial ledger: twenty claims whose truth you already know, some true, some false, some your tomes can't answer. Run the Truth-Seer across them after every change to the charter, the model, or the chunk size, and count how many it gets right. That number is how you know an "improvement" actually improved anything.

trials.py
from truthseer import judge

LEDGER = [
    ("The Rosetta Stone was found in 1799.", "SUPPORTED"),
    ("The Rosetta Stone is written in four scripts.", "REFUTED"),
    ("The Rosetta Stone's carver was named Ptolemy the Scribe.", "NOT ENOUGH EVIDENCE"),
    # add claims drawn from your own tomes...
]

passed = 0
for claim, expected in LEDGER:
    got = judge(claim).get("verdict")
    ok = got == expected
    passed += ok
    print("PASS" if ok else "FAIL", "|", claim, "| expected", expected, "got", got)
print(f"\n{passed}/{len(LEDGER)} trials passed")

The standing wards

  • Always open the source. JEV points you to a page; you confirm it says what JEV claims. Models can misread evidence that's sitting right in front of them.
  • Beware the fluent lie. A confident, well-written answer is no more likely to be true. Hallucination sounds exactly like knowledge.
  • Mind the date. The Mind's memory stops at its training cutoff. For anything recent, rely on the Library or the scrying glass.
  • Your tomes carry their own biases. JEV can only be as balanced as what you feed it. Bind sources that disagree with each other.
  • Keep secrets local. Everything here runs on your machine. If you later swap in a cloud model, your documents travel to that provider.

Paths beyond the ninth circle

  • Save council briefs and verdicts to files so JEV builds a research journal over time.
  • Add a re-ranking step: after summoning ten passages, ask the Mind which five truly bear on the question.
  • Let JEV decide for itself when to consult the Library or the glass, using the model's tool-calling ability.
  • Learn the frameworks others have built for this (LangChain, LlamaIndex) once you understand what they automate.

Appendix

Grimoire of Terms

LLM
Large language model. A program trained on vast text to predict the next word. The Mind.
Parameters
The model's learned numbers. "8B" means eight billion. More usually means smarter, slower, and hungrier for memory.
Quantization
Compressing those numbers (e.g. to 4 bits) so a model fits on ordinary hardware, at a small cost in quality.
Prompt
The text you send. The system prompt is the standing instruction; the charter.
Context window
How much text the model can read at once. Evidence, history, and question must all fit.
Token
A word-fragment, the unit models read and write in. Roughly three-quarters of a word.
Temperature
Randomness of the reply. Near 0 for judgment, 0.7–1.0 for invention.
Embedding
A list of numbers placing text on a map of meaning. Similar ideas sit close together.
Vector database
A store that finds the nearest embeddings quickly. Here, ChromaDB.
RAG
Retrieval-augmented generation. Fetch relevant passages first, then answer from them.
Chunking
Cutting documents into passages small enough to retrieve precisely.
Hallucination
A fluent, confident statement with no basis in fact or evidence.
Agent
A model allowed to choose actions (search, read, calculate) in a loop until a goal is met.
Scribed for the apprentice who would become adept. Copy each spell exactly, test after every circle, and trust no answer you have not traced to its source.
